# 🔬 Featured Projects

## 🛡 SEDAS — Social Engineering Defence and Awareness System

🔗 https://github.com/ailinkon/sedas

**MIS5320 Applied IS Project** — a layered, AI-assisted phishing defence platform built as a team capstone project.

Key components:

- Phishing detection pipeline (TF-IDF feature extraction + Logistic Regression, SVM, Random Forest, XGBoost, Naive Bayes) benchmarked against peer-reviewed published research on an 82,000+ email corpus, with the SVM model reaching **99.16% F1**, beating the published benchmark
- 5-fold cross-validation with statistical significance testing to validate results
- Risk-based awareness training module with adaptive scoring
- Governance dashboard and tamper-evident URL verification registry
- FastAPI deployment with automated testing and CI/CD

The project included structured literature analysis and evaluation against existing published research.
